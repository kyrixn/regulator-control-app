Each bar is the muscle's length in mm from its mapped sensor (band −10…2 mm); the label shows that regulator's pressure with the exact length below it. The top box sets pressure (mV); the bottom box sets a target length (mm) which runs a PID (bottom box highlighted while active). Setting a pressure cancels that muscle's length control. Muscles are capped at 3000 mV. HOLD stops every PID and holds current pressure; STOP vents all; ZERO ALL / CLEAR ZERO set the length datum; SET PID updates the gains live; RESCAN reloads the mapping. 4000
